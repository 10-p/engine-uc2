## Step 0 - reading (2026-10-10)

### 1. The standby check

- `UNetDriver::TickDispatch` (`Source/Engine/Src/UnNetDrv.cpp:244-300`): with `bEnableStandbyCheatDetection` (a file
  static, on; console `TOGGLE_SP` / `SHOW_SP`), a SERVER that has at least one connection for which
  `ShouldIncludeInStandbyCheck` is true and heard no packet from any client for `STANDBYCHEAT_TIMEOUT` (1 s,
  `UnLevel.h:13`) logs `Standby hack detected!` and calls `SetStandbyCheatStatus(true)` -> `Notify->NotifyStandbyHack`
  -> `ULevel::NotifyStandbyHack` (`UnLevel.cpp:1353`): `Standby hack status change detected!  Status now True.` and,
  during a match, `PlayerController.ToggleStandbyMode` -> `SetPause(true)` + the GUI notice. The next packet clears
  it (`UpdateLastReceiveTime`). A CLIENT runs the other half: no packet from its server for 3 s.
- `ShouldIncludeInStandbyCheck` is already virtual (`UnNetDrv.h:93`); Epic overrides it in `UTcpNetDriverXbox`
  (`IpDrv/Src/TcpNetDriverXbox.cpp:391`) to leave LAN clients out on the Xbox. So the web driver overriding it is
  Epic's own mechanism, and the check stays exactly as written for every other driver.
- What it did on the web (E-2, `webrtc.md` step 4 "Loss run 1"): a guest that goes silent (the loss simulation's lost
  close; equally a closed tab or a crash: the glue keeps a pipe for `RECONNECT_GRACE_MS` = 90 s before it reports it
  closed, `packages/glue/src/webrtc/index.js:156`) paused the host's match until `ConnectionTimeout` (60 s) dropped it.
- engine-ut2004's WebRTC driver: no standby check (UT2004 has none).
- Not covered by the override: the CLIENT half (a web guest whose host vanishes runs the 3 s check against its
  server connection, `ShouldIncludeInStandbyCheck` is not consulted there). Left as Epic wrote it (open question).

### 2. Rumble

- `SDL2Pads.cpp` `UpdateBoundPad` -> `UWaveformManager::GetRumbleState` (levels of the current waveform sample,
  `UnForceFeedbackWaveform.cpp`) -> `SetPadRumble` -> `SDL_GameControllerRumble(L, R, 1000 ms)`, refreshed every
  0.5 s while unchanged, 0 to stop. On the web SDL's Emscripten driver has no rumble (`EMSCRIPTEN_JoystickRumble`
  -> `SDL_Unsupported()`, `SDL_GameControllerHasRumble` false); G-5 measured 32 refused requests.
- SDL's Emscripten driver keeps the Gamepad API index private (`SDL_joylist_item.index`) and names the joystick by
  the browser's `Gamepad.id` (`SDL_JoystickName`); `SDL_GameControllerName` is the mapping's name ("Standard
  Gamepad").
- Who rumbles in UC2's scripts: weapons (`UCWeapon.uc` `FireRumble`/`AltFireRumble`/`Pre...`/`Post...`, per weapon
  class defaults), melee hits, and death (`Pawn.Died` -> `ClientPlayWaveform(damageType.KilledWaveform)`, Engine's
  `DamageType` default: 100/100 constant for 0.75 s). `DamagedWaveform` (a hit that does not kill) is None in every
  class we have source for (`DamageType.uc:203` commented out), so "takes a hit" rumbles only when it kills.
- The fake pad (`packages/e2e/lib/fake-gamepad.js`) reports `vibrationActuator: null`.

## Changes (code written before the builds; evidence below per item)

1. `Source/WebRTCDrv`: `UWebRTCNetDriver::ShouldIncludeInStandbyCheck` returns 0.
2. `Source/SDL2Drv` (`__EMSCRIPTEN__` only): at connect, a synchronous main-thread probe (`MAIN_THREAD_EM_ASM_INT`)
   finds the pad's browser index (the `Gamepad.id` SDL reports, n-th of that id) and whether it has a
   `vibrationActuator` with `playEffect` ('dual-rumble'); logged once per connect either way. `SetPadRumble` then
   sends `playEffect('dual-rumble', {startDelay: 0, duration, weakMagnitude: right/65535, strongMagnitude:
   left/65535})` through `MAIN_THREAD_ASYNC_EM_ASM` (the engine never waits) per change of level, with duration =
   the rest of the current waveform sample + 50 ms (re-sent if the level still holds then), and `reset()` when the
   level drops to 0. Native: the SDL call as before (the hold time is computed and not used).
3. `tools/dev/sync-web-ini.py` DELTAS: `AntiAliasing` 4 -> 0 in both device sections of the web file.
4. `Source/UC2ALAudio`: `PlayMusic` plays a WMA music bank's cooked `../Music/<Song>.ogg` when it exists (logged on the
   `playing` line), else the old silence line; `UC2AudioCheck` streams that file in the WMA entry's place.
