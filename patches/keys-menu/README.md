# keys-menu

UCMenu (D-9): the KEYBOARD / MOUSE settings page. `UC2Settings_Main` gets a KEYBOARD / MOUSE button, PC only (5 hunks: the
button, its place in the list, opening the page, freeing it); two new classes: `UC2Settings_Keys` (the page: key
rows from `[Engine.Input]`, conflicts cleared, defaults from DefUser.ini, the mouse sensitivity slider and invert
box) and `KeyBindingPanel` (the list control). The new classes are our own text with its comments (whole files in
`new/`); they need no include file.

- **Ini keys**: writes `[Engine.Input]` key bindings and `[UCGameplay.UCPlayerInput] MouseLookSensitivity`,
  `bInvertMouseLook` (through `SAVECONFIGKEYS`); reads DefUser.ini for the defaults.
- **Depends on**: mouse-look. The page reads and sets `UCPlayerInput.MouseLookSensitivity`/`bInvertMouseLook`
  (12 lines in `LoadMouse`/`SaveMouse` need them to compile), and its two mouse rows (a slider and a check box: 4
  functions, 2 subobjects, about 80 lines in all) only do something with mouse-look. That is not "a few lines",
  so it is not split into a `keys-menu/mouse-rows` set (a split means writing and testing a variant of the page
  without the rows); if wanted, say so.
