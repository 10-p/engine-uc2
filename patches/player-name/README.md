# player-name

GUI (D-4): without a profile, the first player keeps the launcher's name (User.ini `[DefaultPlayer] Name`, which
the launcher sets) instead of being renamed after the selected character; a split-screen guest without a profile
keeps the character's name, as before. One function, `GUIController.SetProfilePlayerName` (the extra blank lines
in the second hunk keep an `assert` further down on the source line its bytecode records).

The shipped GUI.u already has `bUnlockCharacters`/`bShowAllMuts` as `config` (Epic's later source dropped that;
our source put it back), so the base keeps them and this set does not touch them.

**Ini keys**: `[DefaultPlayer] Name` (read). **Package**: GUI. **Depends on**: epic-fixes (both change
GUIController). Generated by `tools/dev/uc-patches-regen.sh` (commits 4069362, fd81f64).
