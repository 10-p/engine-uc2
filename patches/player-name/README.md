# player-name

Without a profile, the launcher's names are the game's: the first player is named by the launcher's player name and
the session he hosts by the launcher's server name. With a profile, the profile's names win (its name, and the server
name saved in it).

GUI: without a profile, the first player keeps the launcher's name (User.ini `[DefaultPlayer] Name`, which
the launcher sets) instead of being renamed after the selected character; a split-screen guest without a profile
keeps the character's name. `GUIController.SetProfilePlayerName` (the extra blank lines in its second hunk
keep an `assert` further down on the source line its bytecode records).

UCMenu: Epic's character page (`UC2Arena_Character.SaveSettings`) names a player who has no name yet in the
GameStartInfo after his character (the network page clears the GameStartInfo, so a host who takes the default
character without changing it gets there); for a player without a profile it asks
`GUIController.SetProfilePlayerName`, which applies the rule above (the character's name stays the fallback).

GUI + UCMenu: without a profile, the first player's session is named by Avaris.ini `[Engine.GameReplicationInfo]
ServerName` (the launcher's server name; read with `GetConfigValue`) instead of the profile default "Liandri
Corporation", which `PlayerProfile.SetServerName` copies over `GameReplicationInfo`'s default at start-up. New
`GUIController.SetProfileServerName`, called where the menus bind the profile's delegates (`ControllerActivated`: the
first menu of a run) and by the host page (`Arena_PanelServerMain.RestoreProfileValues`, before it shows the SESSION
NAME: also after a profile was deleted or cleared to "no profile"); only for the first player's profile-less profile
while it still has the default name, so a SESSION NAME typed on the host page stays. Not from the `SetPlayerName`
delegate: Epic's `NewProfile` resets a profile-less profile into the new one through it, and a new profile starts
with the profile default. A profile's own server name (saved in it) is never touched.

**Ini keys**: `[DefaultPlayer] Name` (User.ini, read), `[Engine.GameReplicationInfo] ServerName` (Avaris.ini, read).
**Packages**: GUI, UCMenu. **Depends on**: epic-fixes (both change GUIController). Generated by
`tools/dev/uc-patches-regen.sh`. Checks: `tools/dev/y1-names.sh` (native, a System Link host through the menus, its UDP
beacon), `tools/dev/d4-names.sh`.
