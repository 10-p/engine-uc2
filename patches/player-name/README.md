# player-name

Without a profile, the launcher's names are the game's: the first player is named by the launcher's player name and
the session he hosts by the launcher's server name. With a profile, the profile's names win (its name, and the server
name saved in it).

GUI (D-4): without a profile, the first player keeps the launcher's name (User.ini `[DefaultPlayer] Name`, which
the launcher sets) instead of being renamed after the selected character; a split-screen guest without a profile
keeps the character's name, as before. `GUIController.SetProfilePlayerName` (the extra blank lines in its second hunk
keep an `assert` further down on the source line its bytecode records).

UCMenu (Y-1): the character page's `UC2Arena_Character.SaveSettings` named a player who has no name yet in the
GameStartInfo after his character (Epic's second place for that rule; the network page clears the GameStartInfo, so a
host who takes the default character without changing it got there): for a player without a profile it now asks
`GUIController.SetProfilePlayerName`, which applies D-4's rule (the character's name stays the fallback).

GUI (Y-1): without a profile, the first player's session is named by Avaris.ini `[Engine.GameReplicationInfo]
ServerName` (the launcher's server name; read with `GetConfigValue`) instead of the profile default "Liandri
Corporation", which `PlayerProfile.SetServerName` copies over `GameReplicationInfo`'s default at start-up. New
`GUIController.SetProfileServerName`, called where the menus bind the profile's delegates (`ControllerActivated`: the
first menu of a run) and from `SetProfilePlayerName` (a profile switched to "no profile"); only while the profile-less
profile still has the default name, so a SESSION NAME typed on the host page stays. A profile created while
profile-less keeps the session name it had (Epic's `NewProfile` resets the profile through the same delegate).

**Ini keys**: `[DefaultPlayer] Name` (User.ini, read), `[Engine.GameReplicationInfo] ServerName` (Avaris.ini, read).
**Packages**: GUI, UCMenu. **Depends on**: epic-fixes (both change GUIController). Generated by
`tools/dev/uc-patches-regen.sh` (commits 4069362, fd81f64; Y-1). Check: `tools/dev/y1-names.sh` (native, a System Link
host through the menus, its UDP beacon), `tools/dev/d4-names.sh`.
