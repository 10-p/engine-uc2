# missing-maps

UCMenu: a map that is not there never comes from a custom map list.

- A custom list keeps its maps as names in the player's profile (`PlayerProfile.SetMaplist`), so a list entry with no
  map would be saved as the name `None`, which the Arena would offer as a map that does not exist.
- `Arena_PanelMaplist` (the Custom list editor): `SaveMaplist` saves only the rows that name a map, and `Done` counts
  only those. A list of nothing but unnamed rows gets Epic's "Custom maplists must contain at least one map".
- `Arena_PanelBase.DropUnnamedMaps` (with `RemoveUnnamedMaps`) drops the entries that are empty or `None` from a custom
  list, and from the profile's copy of it, in the profile's order. A list left empty gets the game's `<Prefix>_Full`
  list, as a new profile does.
- It is called where the menus read a custom list:
  - `Arena_PanelMain.RefreshAvailableMaplists` (the tabs);
  - `Arena_PanelMain.InitializeMaps` (the list read again after the editor);
  - `Arena_PanelMaplist.InitializeMaps` (the editor).

  So a profile saved with `None` is repaired the next time its Arena opens.

**Packages**: UCMenu. **Depends on**: extra-maps: its hunks are in `RefreshAvailableMaplists`, which extra-maps
changes. **Ini keys**: none. Generated by `tools/dev/uc-patches-regen.sh`.
