# mouse-look

The PC mouse for UCGameplay (D-6 and its follow-ups): the mouse turns the view through its own linear channel,
apart from the pad's curve, adhesion and auto-centring; a rigid third-person camera under the mouse (no jitter,
the camera drawn from where the pawn is drawn) or, with `bLazyMouseCamera`, Epic's lazy one; lock-on works with
a mouse; the keyboard moves and strafes; UT2004-style double-tap dodge (G-8); console commands `MouseLookSens`
and `MouseLookInvert` for the session.

- **Classes**: UCPlayerInput (7 hunks), UCPlayerController (9 hunks), UCTrainingController (2 hunks).
- **Ini keys** (User.ini / DefUser.ini `[UCGameplay.UCPlayerInput]`, globalconfig): `MouseLookSensitivity`
  (2.5), `bInvertMouseLook` (False), `bLazyMouseCamera` (False), `bDoubleTapDodge` (False). The shipped package
  ignores them.
- **Network**: UCGameplay is a server package; a network game needs the same package on both sides.
- Generated by `tools/dev/uc-patches-regen.sh` from our source (commits 49d4705 ... b6c0641). **Depends on**:
  epic-fixes.
