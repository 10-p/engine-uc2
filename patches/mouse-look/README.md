# mouse-look

The PC mouse for UCGameplay: the mouse turns the view through its own linear channel,
apart from the pad's curve, adhesion and auto-centring; a rigid third-person camera under the mouse (no jitter,
the camera drawn from where the pawn is drawn) or, with `bLazyMouseCamera`, Epic's lazy one; lock-on works with
a mouse; the keyboard moves and strafes; UT2004-style double-tap dodge; console commands `MouseLookSens`
and `MouseLookInvert` for the session.

- **Classes**: UCPlayerInput (7 hunks), UCPlayerController (9 hunks), UCTrainingController (2 hunks).
- **Who owns the look** (`UCPlayerInput.bMouseOwnsLook`): the mouse (or the look keys) while it moves, the pad as soon
  as one of its sticks moves (the left stick too, so a pad player who only walks has Epic's pad camera: the lazy
  camera, auto-centred pitch, aim adhesion); on PC a player starts with the mouse, except a split-screen
  player on a viewport other than the window's (players 2-4), which the mouse never reaches: always the pad's.
- **Ini keys** (User.ini / DefUser.ini `[UCGameplay.UCPlayerInput]`, globalconfig): `MouseLookSensitivity=2.5`,
  `bInvertMouseLook=False`, `bLazyMouseCamera=False`, `bDoubleTapDodge=False`. The shipped package ignores them.
- **Network**: UCGameplay is a server package; a network game needs the same package on both sides.
- Generated by `tools/dev/uc-patches-regen.sh`. **Depends on**: epic-fixes.
