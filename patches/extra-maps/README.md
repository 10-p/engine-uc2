# extra-maps

UCMenu (ufront, 2026-10-16): the maps a player added (dropped into `Maps/`, or uploaded as a mod on the web) in the map
menus. The engine makes the lists at boot (`Source/Engine/Src/UnExtraMaps.cpp`: `[<Prefix>_Extra]` in `Maplists.ini`
and player counts in `Gametypes.ini`, in memory only); this set shows them:

- `Arena_PanelBase`: a map list `MAPLIST_Extra` (= 9; `MAPLIST_MAX` 10), named `<Prefix>_Extra` (`GetCurrentMaplistName`,
  `GetMaplistIndex` "EXTRA"), and `MaplistAtPosition`: the tabs are shown Custom, Extra, then the game's own lists (the
  constants keep their values; only the display order changes). `GetAllMaps( Maps, bWithExtra )`: with the flag the
  `_Full` maps and the added ones.
- `Arena_PanelMain`: `RefreshAvailableMaplists` walks the lists in that order and keeps the Extra tab's maps; an added
  map's preview is a still (`ExtraMapPreviewMaterial`, the menus' null portrait), never a movie: an added map has none,
  and the retail movie found by the name after the prefix would be another map's (`IsExtraMap`, `GetMapPreview`). The
  tab is shown only when it has maps (as every list: a label and at least one map), and it is not editable (the Edit
  button stays Custom's).
- `Arena_PanelMaplist` (the Custom list editor): offers the added maps too (`GetAllMaps(.., true)`), and shows no
  description rather than `<?...?>` for a map without one (its `.int` is missing).

- **Depends on**: epic-fixes (it rebuilds UCMenu). Placed after player-name and before players34: `uc-patches.py make`
  cannot make a set after one that adds classes (their files have no identity line), and players34, key-glyphs and
  keys-menu add classes.
- Generated by `tools/dev/uc-patches-regen.sh`. Notebook: `docs/porting/analysis/extra-content.md`.
