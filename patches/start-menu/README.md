# start-menu

UCMenu: the start screen's prompt follows player one's device. Epic's Xbox ini opens the game on `UCMenu.StartMenu`, and
`Engine/Config/Default.ini` does too; this set is what makes the screen fit a PC.

- `StartMenu`: on a pad the screen is as shipped: `PRESS START` (Epic's localised caption), and only Start goes on. While
  player one uses the keyboard or the mouse it says the engine's `ANYKEYPROMPT` (`Source/Engine/Src/UnEngine.cpp`: the
  text in the game's language, nothing on a pad), and any key or a left click goes on. Which device: the engine's
  `FKeyGlyphs`, as for the key glyphs: a PC starts on the keyboard, a pad plugged in at the start says "pad", and the
  last device touched decides.
- Keys that do not count: modifiers, locks, Pause, Print Screen, the Windows and menu keys, function keys (F1 is mapped to
  the pad's Back, so it does count) and the console key.

- **Depends on**: epic-fixes (it rebuilds UCMenu).
- Generated by `tools/dev/uc-patches-regen.sh`.
