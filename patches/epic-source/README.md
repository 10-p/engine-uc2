# epic-source

Three places where Epic's later source differs from the shipped package + the load-time patcher, because the
patcher could only replace bytecode (it cannot rename a label, change a default or drop a local). Our current
rebuilt packages come from that source, so this set keeps them as they are; without it a rebuilt UCGameplay
behaves exactly like the shipped one with the title update.

- `CTFFlag.home`: the code under the state's label is `Begin:` (Epic's patch names it `WeaponAbility`, the wrong
  name index, scripts.md finding 1; with the patch a returning flag never runs `Sleep(0.1); CheckTouching()`, so
  an enemy standing on the base gets the flag only on the next touch).
- `OverflowBall`: `bUpdateSimulatedPosition=True` in defaultproperties too (the patched PostBeginPlay sets it as
  well, so both end up True after spawn).
- `UCWeap_Melee.BusyShieldOn.HitWall`: the two unused locals of the emptied function are gone.

Generated by `tools/dev/uc-patches-regen.sh` (those three classes from a build of Epic's later source).
**Packages**: UCGameplay. **Ini keys**: none. **Depends on**: epic-fixes. Default: on (an open question for the
owner: it could be folded into epic-fixes, or left off to keep the title update's exact behaviour).
