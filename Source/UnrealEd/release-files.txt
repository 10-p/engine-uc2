# The editor's files: what UnrealEd.exe needs in the game folder beyond a folder cooked from the retail Xbox disc
# (tools/cook.py) with the Windows release in its System/. The disc already has the editor's script packages
# (Editor.u, UnrealEd.u), its tips and help topics (UnrealEdTips.ini, UDNHelpTopics.ini) and the localisation of
# Editor, UnrealEd, Window and WinDrv; its DefUnrealEd.ini names Epic's D3DDrv, which this build has not, so ours
# replaces it. The bitmaps of the editor's left button bar are read from System/EditorRes/<name>.bmp when the bar is
# made (the modes, the brush builders' BitmapFilename, the [UserDefinedGroup] buttons of UnrealEd.ini, and BBGeneric
# for a button whose own bitmap is missing), the splash from System/EdSplash.bmp; the disc has neither, Epic's drop
# has both.
#
# tools/dev/unrealed-files.sh copies them. One file per line: <source> <path in the source> <path in the game folder>
#   build  the windows build directory
#   repo   this repository
#   epic   Epic's drop (UC2_EPIC_SOURCES, default <repo>/../epic-sources/uc2-avaris-2226)
